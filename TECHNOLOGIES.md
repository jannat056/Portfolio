# Technologies & Tools

This project was built using the following technologies, development tools, and AI-assisted development resources.

## Technologies Used

### HTML5

HTML5 is used to build the structure and semantic content of the website.

It is used for:

- Page structure
- Navigation
- Sections
- Headings
- Paragraphs
- Images
- Links
- Forms
- Buttons
- Semantic HTML elements

### CSS3

CSS3 is used to design and style the website.

It is used for:

- Layout design
- Flexbox
- CSS Grid
- Responsive design
- Typography
- Colors
- Spacing
- Borders
- Shadows
- Hover effects
- Transitions
- Mobile-friendly layouts

## Development Tools

### Visual Studio Code

Visual Studio Code is used as the primary code editor for writing, editing, and organizing the project files.

### Live Server

Live Server is used to run the website locally and preview changes in the browser during development.

### Google Chrome

Google Chrome is used to test the website, inspect the layout, and check responsiveness.

### Git

Git is used for version control and tracking changes throughout the development process.

### GitHub

GitHub is used to store, manage, and showcase the project online.

## AI-Assisted Development

### ChatGPT

ChatGPT was used as an AI-assisted development tool during the project.

It was used for:

- Understanding HTML and CSS concepts
- Planning the project structure
- Generating and improving code ideas
- Debugging and troubleshooting
- Improving responsive design
- Writing project documentation
- Learning best practices

AI was used as a learning and development assistant, while the project was reviewed, customized, and organized as part of my own learning process.
