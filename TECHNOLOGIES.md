# Technologies & Tools

This project was built using various web technologies, development tools, and AI-assisted development resources.

## Technologies Used

### HTML5

HTML5 is used to build the structure and semantic content of the website.

It is used for:

* Page structure
* Navigation
* Sections
* Headings
* Paragraphs
* Images
* Links
* Forms
* Buttons
* Semantic HTML elements

### CSS3

CSS3 is used to design and style the website.

It is used for:

* Layout design
* Flexbox
* CSS Grid
* Responsive design
* Typography
* Colors
* Spacing
* Borders
* Shadows
* Hover effects
* Transitions
* Dark Mode
* Mobile-friendly layouts

### JavaScript

JavaScript is used to add interactivity and dynamic functionality to the website.

It is used for:

* Dark Mode / Light Mode toggle
* Mobile navigation menu
* Button interactions
* Dynamic UI behavior
* DOM manipulation
* Event handling

### TypeScript

TypeScript is currently being learned and practiced as part of my web development journey.

I use TypeScript to practice:

* Type-safe programming
* Functions
* Arrays
* Objects
* Type aliases
* Union types
* Basic problem solving
* Writing more maintainable code

Some learning projects, such as the **Student Result Calculator**, are planned or developed using TypeScript.

### React

React is currently part of my learning journey.

I am learning React to understand:

* Component-based development
* Reusable UI components

* State
* Event handling
* Modern frontend development

## Development Tools

### Visual Studio Code

Visual Studio Code is used as the primary code editor for writing, editing, testing, and organizing project files.

Live Server is used to run the website locally and preview changes in the browser during development.

Google Chrome is used to test the website, inspect layouts, debug issues, and check responsiveness across different screen sizes.
