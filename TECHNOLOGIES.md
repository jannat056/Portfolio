# Technologies & Tools

This project was built using the following technologies, development tools, and AI-assisted development resources.

## Technologies Used

### HTML5

HTML5 is used to build the structure and semantic content of the website.

It is used for:

* Page structure
* Navigation
* Sections
* Headings
* Paragraphs
* Images
* Links
* Forms
* Buttons
* Semantic HTML elements

### CSS3

CSS3 is used to design and style the website.

It is used for:

* Layout design
* Flexbox
* CSS Grid
* Responsive design
* Typography
* Colors
* Spacing
* Borders
* Shadows
* Hover effects
* Transitions
* Dark mode
* Mobile-friendly layouts

### JavaScript

JavaScript is used to add interactivity and dynamic functionality to the website.

It is used for:

* Dark mode / light mode toggle
* Mobile navigation menu
* Button interactions
* Dynamic UI behavior
* DOM manipulation
* Event handling

## Development Tools

### Visual Studio Code

Visual Studio Code is used as the primary code editor for writing, editing, and organizing the project files.

### Live Server

Live Server is used to run the website locally and preview changes in the browser during development.

### Google Chrome

Google Chrome is used to test the website, inspect the layout, debug issues, and check responsiveness across different screen sizes.

### Git

Git is used for version control and tracking changes throughout the development process.

### GitHub

GitHub is used to store, manage, and showcase the project online.

## AI-Assisted Development

It was used for:

### Codex

Codex was used as an AI-assisted coding tool during the development process.

AI tools were used as learning and development assistants. The project was reviewed, customized, tested, and organized as part of my own learning process.
